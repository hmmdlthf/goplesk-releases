# Security

Please report security problems privately, not in a public issue. Use GitHub's **[Report a vulnerability](https://github.com/hmmdlthf/goplesk-releases/security/advisories/new)** form on this repository.

Include the Goplesk version (`goplesk version`), what you found and how to reproduce it. You'll get a reply within a few working days. Fixes are shipped as a new release and noted in its release notes.
